## 四、数据模型与安全核对

- **DDL 规范**：`001_init.sql` 8 张表，BIGSERIAL 主键 / JSONB / TEXT[] / TIMESTAMPTZ / 外键 ON DELETE CASCADE，均有索引，符合任务包 §5。
- **加密**：`crypto.ts` AES-256-GCM（64 hex 密钥 + 12 字节 IV + auth tag），格式 `iv:tag:ciphertext`。
- **脱敏**：`publicModel()` 返回 `api_key_masked`（首 3 尾 4），`api_key_enc` 置 undefined 不外泄。
- **判分器安全**：`judge.ts` 用 mathjs（`create(all)`），无原生 eval；密码锁 `countClue` 逻辑经手工验算，唯一解 12753 对 5 条线索全吻合。
- **密钥不进 git**：`.env.example` 全占位符，`.gitignore` 排 `.env`/`.env.*`/`data/`/`node_modules/`。
