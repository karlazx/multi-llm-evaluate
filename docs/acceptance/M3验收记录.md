## 四、ELO 算法复验

初始双方 1500、K=32，投一票「DeepSeek 赢 / GPT-4o-mini 输」：
- eA = 1/(1+10^((1500−1500)/400)) = 0.5
- DeepSeek = 1500 + 32×(1−0.5) = **1516**
- GPT-4o-mini = 1500 + 32×(0−0.5) = **1484**

与 Claude 汇报实测（1516 vs 1484）完全一致，算法正确。

## 五、口径说明（非缺陷）

- **一致性口径**：`agree` 判定为「人工投票的 winner 其 AI 分 ≥ loser 的 AI 分」。L1 客观题 score 为 0/1、L2 主观题为 0-1，混合比较取的是相对大小而非绝对值，方向一致，不影响一致率语义。
- **抽样模式**：`allPairs` 按用例分组顺序 push，`find` 取每用例首对，即抽样为「每用例随机 1 对」，符合「抽样校准」定义。
