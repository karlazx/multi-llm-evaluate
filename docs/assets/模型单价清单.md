## 四、给开发（Claude）的落地建议

1. **胜算云接入的模型**（GPT-4o-mini、Claude Sonnet 4.5）→ 直接填第二节美元价，无歧义。
2. **DeepSeek 直连** → ✅ 老板已拍板：用 **DeepSeek 官方价、填高峰价**。最终填值（USD/1M）：
   - `deepseek-v4-flash`：`cost_input = 0.444`、`cost_output = 1.333`
   - `deepseek-v4-pro`：`cost_input = 1.333`、`cost_output = 4.000`
   高峰价即费用上界（宁可高估不低估）；若后续要精确区分峰谷，可给 models 表加 `cost_peak/cost_offpeak` 字段。
3. 若希望 DeepSeek 也统一走胜算云（美元计价、免汇率换算），直接用第二节 `deepseek/deepseek-v4-flash` 的 $0.1428/$0.2857 即可。
